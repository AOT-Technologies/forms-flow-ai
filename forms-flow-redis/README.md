# formsflow.ai Redis

This repository contains a Docker Compose configuration to set up a lightweight Redis service using the official Redis image, pinned to `redis:7.2.17-alpine`. Redis 7.2.x is the last release line under the BSD-3-Clause licence; Redis 8.x is licensed under AGPL, RSAL or SSPL, so do not move to it without a licence review.
